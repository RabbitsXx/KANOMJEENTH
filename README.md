# Kanomjeen Server Suite

Custom RocketModFix/LDM plugin suite and Workshop UI source for the **Kanomjeen** Unturned server.

## Target
- Game: Unturned Dedicated Server
- Map: California 2
- Style: Semi-Vanilla Survival PvP
- Framework: RocketModFix / LDM
- Language: C#
- Runtime target: `netstandard2.1`
- Reference packages:
  - `RocketModFix.LDM.Redist 4.9.3.18`
  - `RocketModFix.Unturned.Redist.Server 3.26.3.11`
  - `RocketModFix.UnityEngine.Redist 2022.3.62.3`

## Implemented source modules
1. **Kanomjeen.Core** — combat/raid state, restricted zones, persistent cooldowns, shared cross-feature teleport lock, player resolver, command rate limiting, shared GUI bridge.
2. **Kanomjeen.TPA** — `/tpa`, `/tpahere`, accept/deny/cancel/toggle, warmup, combat/raid/zone restrictions, GUI request handling.
3. **Kanomjeen.Homes** — persistent named homes, limits, teleport cooldown/warmup, GUI list.
4. **Kanomjeen.Kits** — config-driven kits with persistent cooldowns and starter-survival default.
5. **Kanomjeen.Respawn** — short spawn protection ending on movement/attack/expiry.
6. **Kanomjeen.BuildGuard** — placement-time zone/item/type/owner limits without per-frame world scans.
7. **Kanomjeen.Airdrops** — config-driven California 2 spawn points, automatic scheduling, dynamic PvP objective zones and GUI status.
8. **Kanomjeen.Stats** — persistent kills, deaths, KDR, fatal headshots, zombies, playtime and longest life.
9. **Kanomjeen.ServerManager** — autosave, restart countdown, safe save/shutdown and announcements.
10. **Kanomjeen.AdminAudit** — warn/mute/kick/ban/unban/inspect/god/vanish plus buffered JSONL audit logging.
11. **Kanomjeen.VehicleGuard** — lightweight vehicle inspection and event logging. No virtual garage.

## Shared design rules
- New permissions use only `kanomjeen.*`.
- No public `/warp`.
- No unrestricted virtual vault or virtual garage at launch.
- No broad item/vehicle economy shop at launch.
- No VIP combat/raid bypass.
- No end-game starter kit.
- TPA/Home revalidate combat, raid, vehicle, restricted zones and destination immediately before teleport.
- California 2 locations are configured as data; map locations are not hardcoded into gameplay code.
- Airdrops create dynamic objective zones so TPA/Home/Kit cannot trivialize a live PvP objective.
- Persistent data uses batched XML/JSONL writes rather than synchronous writes on every command.

## GUI / Steam Workshop source
`workshop-ui/` contains the Workshop-facing UI source:
- Master Bundle metadata
- Effect asset metadata (default Effect ID `51000`)
- UI contract v1.0
- Unity Editor builder that programmatically creates the `Effect.prefab`
- design system and release instructions

Players open the main UI with `/kjmenu` or `/menu`.

The server-side implementation and handoff package are **source-complete / staging-ready**, but not production-certified. **The final `.masterbundle`, platform bundles and `.hash` are not generated by this repository itself.** Export those in Unity using the Unturned `Project.unitypackage` and Master Bundle Tool described in `workshop-ui/WORKSHOP_RELEASE.md`.
